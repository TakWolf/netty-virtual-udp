# Netty Virtual UDP

[![Java](https://img.shields.io/badge/java-8%2B-brightgreen?style=flat-square)](https://openjdk.org)
[![Maven Central](https://img.shields.io/maven-central/v/io.github.takwolf.netty/netty-virtual-udp?style=flat-square)](https://central.sonatype.com/namespace/io.github.takwolf.netty)

为 [Netty](https://github.com/netty/netty) UDP 提供虚拟连接抽象，将无连接数据报映射为独立的会话通道。

## Installation

```kotlin
implementation("io.netty:netty-all:4.2.13.Final")
implementation("io.github.takwolf.netty:netty-virtual-udp:0.0.3")
```
