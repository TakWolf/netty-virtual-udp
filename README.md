# Netty Virtual UDP

[![Java](https://img.shields.io/badge/java-8-brightgreen?style=flat-square)](https://openjdk.org)
[![Maven Central](https://img.shields.io/maven-central/v/io.github.takwolf.netty/netty-virtual-udp?style=flat-square)](https://central.sonatype.com/artifact/io.github.takwolf.netty/netty-virtual-udp)

一个 [Netty](https://github.com/netty/netty) 虚拟 UDP 库，提供类似 TCP 的传输抽象。

## Installation

```kotlin
implementation("io.netty:netty-all:4.2.12.Final")
implementation("io.github.takwolf.netty:netty-virtual-udp:0.0.1")
```
